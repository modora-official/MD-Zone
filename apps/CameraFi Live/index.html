[Deskripsi Aplikasi]

CameraFi Live adalah apk Android untuk siaran langsung di YouTube, Twitch, & Facebook yang membantu streamer menyiarkan video berkualitas dengan mudah via ponsel. Apk ini juga mendukung beberapa sambungan kamera dan fitur pengeditan video langsung.

[Fitur]

* Pilih Mode

Pilih mode Kamera atau Layar untuk menyiarkan rekaman dari kamera atau layar smartphone Anda.

* Sambungan Kamera Eksternal (memerlukan konverter HDMI ke UVC.)

Mendukung sambungan kamera eksternal. Anda dapat melakukan stream video berkualitas melalui perekaman yg jelas & fungsi zoom memakai kamera USB berperforma tinggi (camcorder, DSLR, dll.).(Maks. FHD/30fps)

* Gambar, Teks, Video, Overlay Audio

Anda dapat menambahkan file gambar/video/audio saat siaran langsung secara mudah. Anda juga dapat menulis hamparan teks.

* Filter Video

Beragam filter video seperti Emboss, mosaic, mono, toon dapat membuat siaran Anda menarik.

* Hamparan Obrolan

Menampilkan data obrolan ke siaran. Obrolan Super juga dapat ditampilkan pada siaran Anda.

* Hamparan Browser Web

Anda dapat menyambungkan platform siaran langsung donasi / pemberitahuan langganan seperti Streamlabs dari sumber web hamparan. Monetisasi siaran langsung anda.

* Efek Gerak

Terapkan berbagai efek keren untuk menarik penonton. Efek gerak mulai dari papan skor ke grafik berita dapat digunakan dalam siaran langsung olahraga, laporan berita, dll.

* Live Poll (YouTube)

Saat merilis produk baru atau mengadakan acara promosi, live poll merupakan cara pemasaran yang bagus.

* Picture in Picture (PIP)

Picture in picture berarti Anda dapat menampilkan dua sumber video sekaligus. Dengan fitur PIP, siaran Anda akan tampak lebih profesional.

* Audio Mixer

Gunakan file musik dengan hak cipta gratis sbg BGM(musik latar) utk siaran langsung Anda.

* Preset

menerapkan berbagai hamparan hanya dalam beberapa klik? Tersedia persiapan siaran yang lebih cepat berkat fitur preset.

* Multiple shot

Dengan kamera smartphone internal, Anda dapat membuat banyak rekaman layaknya memakai beberapa kamera.

* Multi-stream

Anda dapat membuat siaran ke lebih dari 30 platform siaran dengan Restream.

* Live Screen Capture (Game Live)

- Bagikan permainan game Anda di YouTube dan Facebook tanpa memasang perangkat lunak atau perangkat keras tambahan. Anda dapat menyiarkan semua jenis genre game spt RPG, FPS, strategi, puzzle, olahraga, game kartu, dll.

* Simpan Video Langsung

Anda dapat menyimpan video siaran langsung pada memori smartphone Anda untuk membuat video sorotan untuk siaran langsung Anda.

[Spesifikasi]

* Versi Android yg kompatibel

- Android 5.0 atau di atasnya

* Antarmuka

- Sumber video: Kamera internal, Kamera USB, kartu tangkap (HDMI, SDI, CVBS), dan file video

- Sumber audio: Mic Internal, UAC(USB Audio Class), Mikrofon Bluetooth , Internal audio game and file audio

* Server Streaming Langsung yg didukung

- YouTube, Facebook, Twitch, Restream (untuk multi-stream), RTMP, dan SRT

* Ukuran Video

- SD(640×480), HD(1280×720), FHD(1920x1080) ~ hingga UHD(4K, 3840x2160)

(Bervariasi dari platform dan model smartphone)

* Encoder

- H.264 dan HEVC
